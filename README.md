# Ejercicio3-Despliegue-Aplicaciones

![CI](https://github.com/JoaqH-cpu/Ejercicio3-Despliegue-Aplicaciones/actions/workflows/ci.yml/badge.svg)

Web de Náutica Bahía: tienda y alquiler de material náutico en Puerto de Mazarrón.

## Funcionalidades

- Portada con la presentación de la empresa.
- Página de contacto.

## Requisitos

- Un navegador web moderno (sin servidor necesario para la versión estática).

## Cómo ejecutarlo en local

1. Clona el repositorio:

```bash
   git clone https://github.com/JoaqH-cpu/Ejercicio3-Despliegue-Aplicaciones.git
   cd Ejercicio3-Despliegue-Aplicaciones
```

2. Abre `index.html` en el navegador.

## Tecnologías

- **HTML5** y **CSS3**: estructura y estilos de la web.
- *Git* y *GitHub*: control de versiones y colaboración.
- `htmlhint`: validación automática de los HTML.

> Esta práctica forma parte del módulo de Despliegue de aplicaciones web.
